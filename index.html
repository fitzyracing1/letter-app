Step 4: Log & publish

Each finished letter becomes one entry in letters.log, written in the W3C Extended Log File Format. The GitHub Pages site is rebuilt from that log, so each letter gets its own indexable page, plus a letter index and a sitemap.xml. Nothing is uploaded from here. You download the files and add them to the repository yourself.

A recording isn’t needed. If you recorded in Step 3, only its length is logged (x-audio); otherwise that field is -.
